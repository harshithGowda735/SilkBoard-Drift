# SilkBoard-Drift

A 16-bit 2.5D arcade auto-rickshaw racer built in Godot 4.

## Controls
- **A / D** or **Left / Right**: Steer
- **W / S** or **Up / Down**: Speed up / Brake
- **Shift / Space**: Squeeze (two-wheel tilt + speed boost)
- **H**: Horn
- **C**: Toggle retro CRT scanlines
- **R**: Restart after trip over
